# Security policy

Sehat Saathi handles health conversations, so please report vulnerabilities privately instead of opening a public issue.

Use GitHub's **Security -> Report a vulnerability** (private advisory) on this repository. Include what you found, how to reproduce it and the impact. You can expect an acknowledgement within a few days.

In scope: authentication and session handling, the WebSocket voice endpoint, billing and webhook verification, data isolation between users, secrets handling. Never include real patient data in a report.
